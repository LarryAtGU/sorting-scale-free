# Sorting Comparison Network Experiments

This repository contains the code, final protocols, analysis-ready data, raw
execution records, and validation scripts supporting the comparison-sorting SCN
study. It is deliberately limited to material needed to execute, validate, and
reproduce the reported experiments.

## Archived experiments

- Observational panel: 19 algorithms, input sizes 128 through 4096, and 1,000
  deterministic uniform permutations per algorithm-size cell (114,000 runs).
- Temporal mechanism panel: 11 algorithms, input sizes 128 through 1024, and
  200 matched permutations per cell (8,800 runs).

The observational raw archive is stored through Git LFS. Install Git LFS before
cloning if the complete per-execution records are required.

## Repository layout

```text
configs/              Experiment configurations and code manifest
data/generated/       Input-manifest hashes; permutations are regenerated by seed
data/results/         Deposited raw, summarized, and derived results
docs/                 Final protocols and measurement definitions
scripts/              Validation, secondary analysis, and figure generation
src/scn_sorting/      Instrumented algorithms and experiment implementation
tests/                 Correctness and measurement tests
```

Interactive viewers, exploratory pilot outputs, planning notes, and obsolete
raster-figure generators are intentionally excluded from the research archive.

## Installation and tests

```bash
./scripts/install_dependencies.sh
source .venv/bin/activate
python -m pytest
```

## Deterministic inputs

Inputs are uniform permutations generated deterministically from `(n, seed)`.
The experiment uses sizes `{128,256,512,1024,2048,4096}` and seeds 1--1000.
Regenerate and validate them with:

```bash
scn-generate-inputs
scn-test-randomness
```

The committed manifests under `data/generated/` identify the generated files;
the permutations themselves are omitted because they are exactly reproducible.

## Run the experiments

The observational configuration is `configs/paper-final-19-algorithms.json`.
For an explicitly selected run, use:

```bash
scn-run-batch --distribution-only --sizes 128 256 512 1024 2048 4096 \
  --first-seed 1 --last-seed 1000 --label paper-final-19-algorithms
```

Run or resume the temporal experiment with:

```bash
./scripts/run_temporal_mechanism.sh
```

Both runners write checkpoints for crash recovery. Checkpoints are excluded
from the archive because the compressed final run records supersede them.

## Reproduce the reported analyses

From the repository root with the environment activated:

```bash
python scripts/validate_frozen_results.py
python scripts/analyze_secondary.py
python scripts/analyze_theory_validation.py
python scripts/make_vector_paper_figures.py
```

The first three commands reproduce the deposited JSON analysis outputs. The
last command creates the ten vector manuscript figures in the sibling
`over-leaf/figures/` directory.

## Deposited data

The archive contains:

- the full observational per-execution record (`114,000` runs, Git LFS);
- the observational algorithm-size summary, including per-cell histograms;
- the complete temporal per-execution record (`8,800` runs, Git LFS);
- temporal snapshots, global exposure rates, summary, manifest, and run log;
- statistical-validation, secondary-analysis, and theory-validation
  outputs; and
- input randomness report and permutation manifests.

See `data/README.md` for exact filenames and integrity commands.
