# Experiment configurations

Configuration files define input sizes, trials, seeds, algorithms, metrics, and
output formats.

- `paper-final-19-algorithms.json` freezes the confirmatory 19-algorithm,
  six-size, 1,000-seed production design.
- `paper-final-code-sha256.txt` identifies the exact implementation files frozen
  for that run.

The human-readable preregistration is in
`docs/frozen-analysis-protocol.md`.
