# Random-BST and first-pivot Quicksort SCN theory

## Scope

These statements apply to distinct keys inserted into an ordinary unbalanced
binary search tree and to canonical stable first-element-pivot Quicksort, which
compares the pivot with every remaining element once while preserving relative
order in both partitions. They do not automatically apply to AVL rotations,
Hoare's in-place partition scheme, median-of-three or dual-pivot partitioning,
Introsort, or other implementation variants.

## Proposition 1: exact node degree

Let `T` be the BST obtained by inserting a permutation, and let `v` be one of its
nodes. During insertion, `v` is compared once with every ancestor on its search
path. Every node subsequently inserted into the fringe subtree rooted at `v`
also compares once with `v`, because its search path passes through `v`.
No other record compares with `v`. Therefore the simple undirected degree of
`v` in the sorting comparison network is exactly

`degree(v) = depth(v) + subtree_size(v) - 1`.

The directed orientation from smaller to larger keys changes in-degree and
out-degree but not this total-degree identity.

## Proposition 2: Quicksort graph correspondence

For a permutation of distinct keys, the first inserted key is the BST root.
First-element-pivot Quicksort compares that same key with all other records and
recurses on the smaller and larger subsequences. BST insertion sends precisely
those smaller and larger records into the left and right subtrees while
preserving their relative insertion order. Induction on the subsequence size
therefore gives the same ancestor--descendant pairs. Hence the BST insertion SCN
and canonical stable-partition Quicksort SCN have the same distinct comparison
edges for every input, not merely the same expected comparison count.

The experiment's algorithm named `quick` instead reproduces the historical
Hoare-style implementation. Swaps change relative order within later partitions,
and scan boundaries can introduce a different distinct comparison pair. The
repository contains an explicit four-key counterexample, so the inputwise graph
theorem must not be attributed to that implementation. Its exponent near two is
empirical unless a separate equality-in-distribution argument is established.

The repository verifies this identity on explicit inputs and exhaustively
verifies the subtree-count formula below through `n=7`.

## Proposition 3: random-BST subtree-size profile

For a BST generated by a uniform random permutation of `n` keys, the expected
number `N_s` of nodes whose fringe subtree contains `s` nodes is

`E[N_s] = 2(n+1)/((s+1)(s+2))` for `1 <= s < n`,

with `E[N_n]=1` for the root. Thus, away from the root boundary,
`E[N_s]` is asymptotic to `2n/s^2`.

One elementary derivation uses rank intervals. A set of `s` consecutive ranks
forms a fringe subtree exactly when the first inserted key among that interval
and its at most two adjacent boundary ranks belongs to the interval, and the
earliest key within the interval separates it from both boundaries. Summing the
resulting probabilities over the `n-s+1` intervals, with endpoint corrections,
gives the formula above.

## Consequence for degree tails

Subtree size has a probability mass proportional to `s^-2` for a uniformly
selected node. Proposition 1 adds node depth. Typical random-BST depths are of
logarithmic order, whereas large fringe-subtree sizes can extend to order `n`.
Consequently, in the range where subtree size dominates depth, total degree is
expected to exhibit an approximately exponent-two regime, modified by:

- an additive depth contribution in the body;
- dependence between depth and subtree size;
- a finite-size boundary at degree `n-1`;
- the exceptional root and other boundary effects.

This is an explanation for a finite-size, power-law-like region, not a claim
that a finite SCN has an unbounded exact power-law distribution. It also explains
why a very large pooled-sample goodness-of-fit test can reject an exact power law
while estimating an exponent close to two.

## Endogenous attachment interpretation

After `i` keys have been inserted, a node whose fringe subtree has size `s_v`
owns `s_v+1` of the `i+1` external insertion gaps. A new key of uniformly random
rank therefore enters its subtree with probability

`Pr(new key passes through v | current tree) = (s_v+1)/(i+1)`.

When this occurs, `v` gains one new comparison neighbor. Growth is therefore
linear in its current descendant-based degree plus one. This supplies a precise
endogenous preferential-growth mechanism for the random-BST model. It should
not be generalized to every sorting algorithm without a separate proof.
